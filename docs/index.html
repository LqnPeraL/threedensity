Install once. Launch forever.

The launcher keeps the build current against GitHub Releases — no manual re-download when patches drop.

Get the launcher

Download ThreeDensitySetup.exe — a small updater, not the full game archive.

Run it once

It installs under your user folder and creates a Three Density desktop shortcut to the launcher.

Always use the shortcut

Every start checks for a newer release, updates if needed, then opens the game.
